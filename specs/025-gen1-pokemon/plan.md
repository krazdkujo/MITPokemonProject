## Implementation Phases

### Phase 1: Pokemon Data Filtering

1. Read `Source/pokemon/pokemon.json` (1,142 entries)
2. Filter to entries where `number >= 1 AND number <= 151`
3. Write filtered array back to file
4. Validate: Exactly 151 entries, all numbers in range

### Phase 2: Location Encounter Updates

1. Read `Source/locations.json`
2. For each location, filter `pokemon[]` array to valid Gen 1 IDs
3. Write updated locations back to file
4. Validate: All Pokemon references exist in filtered pokemon.json

### Phase 3: Evolution Chain Updates

1. Read `Source/evolution/evolution.json`
2. Remove entries for Pokemon #152+
3. For remaining entries, remove evolution targets #152+
4. Write updated evolution data back to file
5. Validate: All referenced Pokemon are Gen 1

### Phase 4: Image Cleanup

1. List all files in `public/images/pokemon/`
2. Delete files matching pattern `[152-1025].png`
3. Validate: Only 152 files remain (1-151 + placeholder)

### Phase 5: Database Migration (Optional)

1. Query `player_pokemon` for records referencing Pokemon #152+
2. Delete or nullify invalid records
3. Validate: All `pokemon_id` values are valid Gen 1

### Phase 6: Verification

1. Start dev server: `npm run dev`
2. Test starter selection (Gen 1 starters only)
3. Test wild encounters (Gen 1 Pokemon only)
4. Test battle system (no errors)
5. Verify all Pokemon images load
6. Run `npm test` and `npm run lint`
